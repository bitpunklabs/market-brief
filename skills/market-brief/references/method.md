# Shared research method

Define coverage before searching for a preferred explanation: benchmarks,
participation, major economic categories, macro/policy, material entity events,
and systemic risks. Record each required area's status as checked,
checked_no_change, not_checked or failed. User focus supplements the scan;
an explicitly restricted universe changes the scope and the report label.

Use search to discover, original publications to verify. Capture the actual
supporting excerpt or locator, publisher, first-public time, relevant page
version, retrieval time and measured period. Republishing the same event is
not independent confirmation. Unknown times need a reason and a narrower claim;
a date-only timestamp cannot resolve intraday causality.

Build Evidence → Observation → Claim → report. For important changes, explain
new fact → sourced expectation gap → transmission → observed response → next
test. Without a sourced pre-release expectation, compare with the prior state
without calling it a consensus surprise. Distinguish fact, inference and
hypothesis. A causal interpretation needs timing, mechanism and alternative
explanations; price correlation alone is insufficient.

Evaluate economic/operating trend, market pricing and catalyst realization
separately. For a theme identify drivers, transmission, affected entities,
pricing confirmation, counterevidence and next checkpoint. One daily move or
headline does not reset a multiweek thesis. Unknown or mixed is preferable to
an invented precise cycle stage. Representatives need actual economic exposure,
not merely a thematic label.

Freeze as_of before research. Record actual quote endpoints independently.
Later disclosures about an earlier period may measure that period but cannot
serve as contemporaneously known catalysts. Later webpage additions require
version evidence. Period-after updates stay separate from period attribution.
Unknown observations remain null with a reason, not zero.

The outlook has base, improving and deteriorating paths, each with a trigger,
observable confirmation, invalidation, and horizon. Start at cutoff; distinguish
elapsed outcomes from future tests. Do not invent calibrated probabilities,
technical levels, index contributions or hidden-position explanations.

Review previous views only from accessible original reports. Keep original
publication time, trigger, horizon and text. Evaluate direction, mechanism,
timing and risks separately using supported, partially_supported, invalidated,
not_triggered or awaiting_validation. Historical reruns do not enter the live
forecast record. With no old report, omit scoring and still complete analysis.

Write conclusions first; include market/macro/event analysis, selected themes,
conditional outlook and event risks. Short tables are useful when comparing
conditions. Quantities in cadence references are focus targets, never quotas.
Use public Markdown source links near supported facts; no internal search IDs.
US/Crypto material event clocks also show Asia/Shanghai. Omit empty optional
sections and disclose material gaps once near the affected conclusion.

Review decisive sources and counterevidence, numeric bases, sample definitions,
release/price order, historical availability and chapter consistency. Perform
one concentrated evidence repair and targeted revision; if still unsupported,
remove or narrow the conclusion. Research quality is complete/partial/unavailable
as a semantic judgment, separate from code checks, saved files or model routing.
