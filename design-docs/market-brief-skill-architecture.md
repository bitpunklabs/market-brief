# Market Brief Prompt Skill：技术设计

日期：2026-10-07。当前架构：一个可移植prompt生成skill和11份完整模板。功能约定见[功能设计](./market-brief-skill-design.md)。

## 1. 最小组成

```text
initial-prompts/                     从原始11份prompt演进的源模板
skills/market-brief-prompt/
  SKILL.md                          识别请求、选模板、适配与完整交付
  assets/prompts/                    相同11份模板的可移植副本
design-docs/
  market-brief-skill-design.md       功能与prompt保真要求
  market-brief-skill-architecture.md 技术设计与验收边界
```

`initial-prompts/` 是仓库中的原始设计源，`assets/prompts/` 是安装包内副本。维护模板时同步两处并比较字节内容；它们不是两套不同研究策略。独立安装时复制整个skill目录，入口只引用目录内部资源，不能依赖仓库外的相对路径。

本版不需要运行时代码、第三方库、registry、模型客户端、数据库或后台服务。11个组合的模板索引直接放在SKILL.md。模板保留完整市场/频率语义，不拆成通用规则片段再拼回报告。

研究原则维护时同步全部相关模板：基本面与其定价反应是唯一研究范围；后市展望围绕前文关键问题形成具体判断，观察方向和反证自然表达。生成入口不得重新补入固定情景、时段清单或技术分析。

## 2. 生成流程

```mermaid
flowchart LR
  A[用户市场 频率 参数] --> B[读取对应完整模板]
  B --> C[适配明确参数 检查一致性]
  C --> D[交付完整 prompt]
  D --> E[执行端模型完成联网研究与报告]
```

A到D是本skill职责。E属于用户的执行端。生成prompt与执行研究分开，执行端接收一份完整上下文，不通过多个worker或模型档位交换摘要。

仅加载所选模板，避免11份不同频率规则混入同一生成上下文。无参数请求直接保留完整模板；有明确参数时增加简短请求说明，必要时一致修改对应要求。不得用前置说明掩盖正文内相反的语言、日期、范围或长度规则。

## 3. 参数和时间处理

参数由生成agent根据用户原文适配，不引入必须填写的JSON协议或占位变量引擎。

- 日期、截止、限定范围按用户提供的值进入prompt；缺少的可选项保留原模板默认规则。
- 运行时的当前时间、交易日历、夏令时、完整周/月与价格端点由接收模型核验。prompt生成时不冻结成某一天的研究context。
- 历史日期保留当时可知信息边界；明确要求期后更新时分列，不能覆盖历史归因。
- 输入的关注方向不替代广泛扫描；明确限定范围时才修改覆盖。
- 原始模板默认中文。改变报告语言时统一修改相关段落，不能仅根据英文模板正文推断报告应为英文。
- 可用前期报告通过明确附件或路径交付；未提供时保留原模板“实际可取得才复核”的约束。

生成agent只调整任务说明，不执行研究来填补模板，不在prompt里预写市场结论。

## 4. 模型与effort边界

模型与effort由用户在执行端配置。生成prompt只包含研究任务，不附带模型选择、effort或执行配置交接说明，也不在模板中写死型号。

同一个模型仍然可以使用联网、页面读取和必要计算工具；“完整执行”不等于跳过核验或禁止算术工具。这些工具由执行模型根据完整prompt调用，项目不为其规定任务图或报告记录schema。

## 5. 输出与保存

默认直接输出完整prompt正文，用户指定文件时保存UTF-8 Markdown。产物自包含，不依赖skill文件路径、隐藏引用或后续片段；执行模型只拿到这份文本也能理解任务和交付要求。

本项目不生成 `brief.md` / `run.json` 研究包，不把已有历史模拟结果当成本版执行证明。研究报告的保存位置由prompt中的用户要求和执行端工具决定。

`temp/` 保留历史实验和当前验证样例，继续Git忽略；不会复制进skill安装包。Git历史保留撤回前的实现，当前工作树仅保留prompt生成架构。

## 6. 验证与验收

本地验证包括：skill frontmatter和名称有效、11个内部模板链接可访问、安装包可独立读取、11份模板与维护后的源文件一致，以及生成样例包含完整模板内容。与Git历史核对变更范围，确认日期、语言、来源与其他数据规范未被意外改写。

手工审查参数冲突、模板遗漏、历史截止、语言适配与运行时日期语义，并检查展望是否围绕核心问题而非固定情景、技术结构或重复清单。重要场景包括A股长假、美股夏令时、盘后消息与盘中归因、Crypto连续市场、没有前期报告及数据不可得。模板已有对应要求；无需为恢复工作另建研究校验框架。

本地验证证明包和prompt完整性，不证明运行时取到全部数据、模型确实使用最高配置或报告质量提高。真实报告质量需要完整prompt在目标模型上的实际执行与人工评审。
